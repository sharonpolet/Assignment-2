# Assignment 2 — Employee Dashboard

## Features
- React navbar with Home and Employee Form links
- Dashboard fetches users from `https://jsonplaceholder.typicode.com/users`
- Table displays ID, name, and email
- Employee form fields: Name, Designation, Location, Salary
- React Router navigation
- Bootstrap 5 plus custom responsive CSS

## Run on Windows
1. Extract this ZIP.
2. Open CMD in the folder containing `package.json`.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL Vite prints, usually `http://localhost:5173/`.

## Notes
This assignment does not require MongoDB or a backend. The form validates input and displays a success message; it does not store records in a database. Internet access is required to load dashboard users.
